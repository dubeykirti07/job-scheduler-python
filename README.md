# Job Scheduler Python

A Python-based implementation of different job scheduling algorithms and task execution models.

## Features

- FCFS (First Come First Serve) Scheduler
- LIFO (Last In First Out) Scheduler
- Priority Scheduler
- Synchronous vs Asynchronous Task Execution Demo

## Project Structure

```
job-scheduler-python/
│
├── fcfs_scheduler.py
├── lifo_scheduler.py
├── priority_scheduler.py
├── async_sync_demo.py
└── README.md
```

## Scheduling Algorithms

### FCFS Scheduler
Executes jobs in the order they arrive.

### LIFO Scheduler
Executes the most recently added job first.

### Priority Scheduler
Executes jobs based on assigned priority.

### Async vs Sync Demo
Demonstrates the difference between synchronous and asynchronous execution using Python asyncio.

## How to Run

```bash
python fcfs_scheduler.py
python lifo_scheduler.py
python priority_scheduler.py
python async_sync_demo.py
```
